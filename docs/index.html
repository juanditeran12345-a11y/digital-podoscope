Usar el celular como cámara en Windows 11
  1. En el celular Android abre la app Link to Windows y vincúlalo con el computador.
  2. En Windows entra a Configuración, Bluetooth y dispositivos, Dispositivos móviles, y activa Usar como cámara conectada.
  3. Pulsa Actualizar lista y elige el celular en el selector de cámara.
  4. Pulsa Iniciar cámara. El indicador de arriba muestra la resolución real que entrega el celular.
